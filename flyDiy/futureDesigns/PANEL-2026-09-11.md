## Context

The interior view exists (G107/G141 cockpit mode, eye off the pilot's head
bone, the dash solid, seats, and since G240 a stick/throttle/pedals that MOVE
from `sim.ctl`). What sits on the dash is decoration: `buildPanel`
(`tools/_cage_crew.js:925-1040`) draws bezel + black disc + ONE needle at a
name-hashed angle per instrument — no faces, no scales — and it is merged by
material into the flight bake. The fit is one enum (`spec.systems.fit`
minimal/basic/ifr) billed as a lump (`GEN_SYSTEMS`, `60_gen_spec.js:1362`).
The aeroplane's lights are editor rows (`P.li_*`) baked into material
emissive; no emissive crosses the join, so in flight every lamp is dark and
nothing can be switched (`_cage_light.js:209-222`, `_cage_join.js:1689-1756`).
`sim.out` has no rpm, no fuel quantity, no load factor; nothing burns fuel
(`setNodeMass` exists, `30_solver.js:768`, and nothing calls it).

**The brief:** real instruments (quality 3D gauges, accurate readings, well
placed on the dash); minimum set ASI, altimeter, attitude, VSI, compass,
clock, tacho, fuel; switches for exterior lights, dimmers for interior
lights; a key, battery and alternator switches; a simple radio, maybe a
transponder; honest prices and weights; exterior view: click engine / wings
/ gear / tanks / fuselage / pilot for in-flight figures; interior view: no
pilot dummy, the mouse works the cockpit. Glass panel + GPS later, designed
for now. "No need to have more than needed."

## SESSION 1 — THE SOURCES (core) [M]

Everything a needle reads must exist honestly before a needle exists.

**1a. Shaft speed — `genShaftRpm(pp, thr, V, sigma, powerK)` in 60_gen_spec.js.**
Fixed-pitch propeller, flat engine torque with throttle, quadratic torque
fall-off with advance ratio (the same shape as the model's own thrust law):
```
Qe = thrEff · powerK · Qr                         (Qr = Pr / ωr, flat with n)
Qp = Cq0 · ρ · D⁵ · (n² − (V / (D·J1))²)         (Cq(J) = Cq0·(1 − (J/J1)²))
→   n = sqrt( thrEff · (powerK/σ) · nS² + (V / (D·J1))² )
nS = propStaticK · nR   (GEN_RULES.propStaticK = 0.92: A-65/74CK 2150/2300,
                          O-200 2400/2750 → 0.87-0.94 band; documented)
J1 = V0 / (nR · D)      (torque runs out where the model's thrust runs out)
thrEff = idle + (1 − idle)·thr,  idle = (0.28·nR / nS)²   (A-65 idles ~650)
```
Checked on the A-65 (V0 = 1.95·48500/1202 = 78.7 m/s): static 2116, climb
24 m/s 2225, cruise 33 m/s 2325 — the J-3's real 2150 / 2200-2250 / 2300.
Dead engine: `n = V/(D·J1)` (windmilling) — falls out. Electric rows: the
same law (flat torque). Turbine rows: constant-speed → `rpm` = governed
100 % Np, the gauge is torque %. `sim.out.rpm[i]` per engine, computed in
the thrust pass (`30_solver.js:496-520`) from `ctl.eng[i]` and `out.powerK`.
Every POWERPLANTS row gains `rpm` (GATE ATMOS-style census: every row must
carry it; the custom row already does, `60_gen_spec.js:3142`).

**1b. Fuel burn and pack discharge — the P4 remainder (ROADMAP:423).**
Per substep in `30_solver.js`: `kgH = burnKgH · thrEff · powerK` (the thermo
sheet's `burnKgH`, `00_registry.js:432-449`, is the rated figure; SFC flat
with power, idle floor via thrEff); drain every `mFuel` node in proportion
(`nodes[i].mFuel` recorded at `61_gen_frame.js:1581`) through `setNodeMass`;
publish `sim.fuel = { kg, litres, perVessel[] }` (litres via the vessel's
`kgL`). Packs: `soc −= drawKW·thrEff·dt/3600 / kWh`, no mass change. Fuel
exhausted or soc 0 → `sim.eng.running = false` (thrust 0, rpm windmills).
Circuits burn ~0.5 kg on a Cub: re-bless ENERGYBASE / WINGSPLIT / GEN
SHAKEDOWN once (`--bless` is the designed path — memory G99). **Baseline
battery first** (the rule from the energy arc), then the edit, then diff.

**1c. Load factor and rates.** `out.nz` = ((cgVel − prevCgVel)/dt − g)·yUp / g
(one previous-velocity vector kept in the solver; per substep, then
averaged to the step); `out.nzMax` since reset. Yaw rate `out.r` (heading
finite-difference, the pilot's own filter at `43_pilot.js:513`) so the turn
coordinator has a source; `out.beta` (the `flDbg` formula, app.js:3450) so
the slip ball does not recompute it.

**1d. Engine state.** `sim.eng = { running: true, key: 'both', starter: 0 }`
per engine; `sim.setEngine(i, patch)`. START: if `elec.starterOk` → crank
1.5 s → running. Hand-prop: an action (input.js `propSwing` step) on a build
with no starter. The pilot (`43_pilot.js`) sets `key:'both', running` in its
start phase; `makeTestPilot` likewise. Gates fly untouched.

**Gate:** `tools/_rpm_check.js` folded into GATE ENERGY's file or its own
`GATE RPM` (core): the A-65 anchors above within ±3 %, monotone in thr and
V, windmill at thr 0 in flight, every registry row carries rpm, burn drains
to zero and stops the engine, nz = 1.00 ± 0.02 in trimmed level flight and
> 1.5 in a 60° bank (fly it through circuit_harness).
