The flow

  • Phone: Send → the file through the share sheet (Web Share API level 2, navigator.share({files: [build]})): mail it to yourself, WhatsApp it, Messenger, Drive. No backend: the user's own channels carry it. Chrome's share sheet takes a permitted list of file types. If canShare refuses .json, the same bytes go as My Cub.flydiy.txt. The link, the QR and a plain download are the other buttons.
  • Receiving: the computer opens the mail or WhatsApp Web attachment, or drops it on the garage. Import accepts .json and .txt. With the PWA installed, a desktop double-click on the file opens flyDiy (file_handlers), and on a phone flyDiy appears in the share sheet (share_target).
  • The link: #build=1.<base64url(deflate-raw(JSON))>. The fragment never reaches the server, so GitHub Pages stays static. 1. is a patch over a frozen base, 0. is a whole spec.
  • Computer: the page sees #build= before the welcome screen. After the boot it shows this card. Open = today's import path (GARAGE_SPEC load: normalise, migrate, clamp), saved as a new slot. The hash is then cleared, so a reload does not import twice.
  • What the phone could not do happens on the computer: the bench, the flown bake, the world.
