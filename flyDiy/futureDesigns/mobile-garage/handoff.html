Made on a newer flyDiy than this one? You are told, and it still opens (unknown rows keep their defaults).

The flow

  • Phone: Send → the share sheet (Web Share API, navigator.share({title, url})) is the default. QR and copy are the fallbacks, and the .json file is always there.
  • The link: #build=1.<base64url(deflate-raw(JSON))>. The fragment never reaches the server, so GitHub Pages stays static. 1. is a patch over a frozen base, 0. is a whole spec.
  • Computer: the page sees #build= before the welcome screen. After the boot it shows this card. Open = today's import path (GARAGE_SPEC load: normalise, migrate, clamp), saved as a new slot. The hash is then cleared, so a reload does not import twice.
  • What the phone could not do happens on the computer: the bench, the flown bake, the world.
