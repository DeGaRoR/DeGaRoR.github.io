degaror.github.io / laboratory

Cybernetic experiments

Several sandboxes about the same old question: how far can you get with feedback alone? No neural nets, no planners — sensors wired to motors, cells wired to neighbours, tubes wired to whatever is flowing through them. Then you watch.

House rule

Each experiment is a full-screen canvas app that takes over the page. Opening one unloads this menu, so only a single simulation is ever running — nothing stacks up in the background, and phones stay cool. Use Back, or the title in the corner, to return here.

How to read them

All of these are laboratories, not games. There is no score and nothing to win — every one has a settings panel where a single parameter is worth changing at a time. Then leave it running for a minute.

On your phone

Built portrait-first: everything is one-thumb reachable and canvases scale to the screen. Pause (or stop the run) before you go digging in a settings panel — it saves the battery.

Under the hood

Vanilla JS, one self-contained HTML file each, no dependencies and nothing to install. Every simulation loop is requestAnimationFrame-driven, so a backgrounded tab does no work at all.
