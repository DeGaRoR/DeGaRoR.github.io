🚀 Envoyer sur l'ESP32

      

    1. Ouvre Arduino IDE → Fichier › Nouveau, efface tout, colle le code.
      2. 

    2. Carte : ESP32 Dev Module. Port : celui qui apparaît quand l'ESP32 est branché.
      3. 

    3. Clique sur la flèche ➡️ Téléverser. Si ça bloque sur « Connecting… », maintiens le bouton BOOT de l'ESP32.
      4. 

    4. Ruban : DIN sur la broche données, GND sur GND, 5V sur VIN (5V).
      5. 

    5. Bouton : une patte sur la broche, l'autre sur GND.
      6. 

    6. Potars : pattes des côtés sur 3V3 et GND, patte du milieu sur la broche.
